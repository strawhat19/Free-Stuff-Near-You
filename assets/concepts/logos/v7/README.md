# Free-Stuff-Near-You · Logo Concepts v7

Status: **unadopted refinements for review**. This round follows the user's requested **F$NY** treatment: the **S in FSNY is replaced by a literal dollar sign**, and a small zero is included inside the tag. All v1–v6 artwork is preserved. The full display name **Free-Stuff-Near-You** remains unchanged in every lockup.

The selected soft-rounded matched-point geometry, common −8° tilt, and six green palettes from v6 remain. All six variants use the same placement rather than changing the logo layout across colors.

## Lettering

The primary literal **F$NY** is one coherent editable SVG text element with adjacent tspans, set in `Arial, Helvetica, sans-serif`, weight 700, size 22, with 0.3-unit tracking. F, N, and Y use `#214E3B`; the dollar uses the subtle palette accent. It is not still spelled FSNY, and the dollar has the same type size and weight as the initials it joins.

A smaller **0** is set at size 14, weight 700, in `#214E3B`, inside the main tag body at x=54, baseline y=94. It sits directly beneath the dollar's approximate center, with deliberate breathing room, so it remains a secondary free-value cue instead of competing with F$NY. The zero is not outside the silhouette or floating near the tip. Both text elements and the entire contour share **one `rotate(-8 80 80)` group**, preserving the tag's angle.
