# Free-Stuff-Near-You · Logo Concepts v3

Status: **unadopted refinements for review**. This round continues the selected **Open Value** family from v1 and all three soft-green tag shapes explored in v2: the original sage tag, gently tilted mint tag, and rounded ticket. Previous rounds remain unchanged. The six options are refinements across those three shape directions, responding to the request for clean dollar signs, FSNY and unlettered variants, and a lower contained piece that reads as a local map pin.

The new dollar signs are **standard Arial Bold glyphs**, not the uneven custom strokes from v2. The `$0` and `FSNY` letterforms remain live editable SVG text. The lower local piece is connected beneath each tag, aligned to a common center, and contains a transparent circular opening. The composition is a contained tag-and-local-base identity, with no separate floating pin. Mint Tilt's face and lettering share an eight-degree angle while its attached lower local base remains upright.

The same product assumption remains: a future local free-item discovery and community reuse app. No product functionality or approved identity is implied. The full display name remains **Free-Stuff-Near-You** in every lockup. `FSNY` is an optional compact initial treatment only.

All twelve logo SVGs have transparent surrounding canvases, accessible titles and descriptions, vector tag and pointer paths, and useful viewBoxes. Tag holes and the circular local-base opening are true transparent cutouts through even-odd vector paths. The tag face sits over the connected lower base, keeping the composition contained. Rounded $0 Local retains the capsule-like left end from Gentle Ticket in v2 while keeping the right-facing tag point.

The `$0` glyphs use `Arial, Helvetica, sans-serif`, bold weight 700, at 42 units in the standalone mark. FSNY uses the same family at 22 units with 0.3 units of tracking. The full wordmark uses `Avenir Next, Trebuchet MS, Arial, sans-serif`, bold weight 700. No font binaries are bundled. A system without Arial may use its Helvetica or sans-serif fallback, which can shift widths. Before adopting a final identity, choose and license the final font and outline the approved text if fixed rendering is needed. Live text deliberately preserves editability in this review round.

`00-concept-sheet.svg` is a flat 1600 × 1540 comparison sheet with a three-column by two-row card layout, color identities, and compact monochrome design samples at 32, 48, and 64 px wide. `00-concept-sheet.png` is the companion raster export for convenient preview and sharing; SVG remains the editable source. The sheet uses paper `#F1F5EF`, cards `#FFFFFF`, secondary text `#5B7063`, and dividers `#D6E3D9`. It is a concept deliverable, not an application mockup or UI check. Compact samples communicate design intent; no device or browser validation has been run.

No application assets, implementation files, prior concepts, or remote repositories were changed. No option has been adopted. These files have not been tested, built, committed, or pushed.
