# Free-Stuff-Near-You · Logo Concepts v4

Status: **unadopted refinements for review**. This round continues the selected Open Value price-tag family and the sage, mint-tilt, and rounded-ticket directions from v2–v3. All earlier rounds remain unchanged. The same six $0, FSNY, and plain treatments remain in the same three-column by two-row comparison layout.

The critical change is the silhouette: the price-tag face and the lower local point now form **one continuous outer vector contour with one green fill**. Broad, curved shoulders flow directly into a rounded map-pin-like endpoint. There is no overlapping pointer object, darker base, narrow neck, separate lower fill, or visible join. The lower local point is part of the tag itself. One transparent tag-hole cutout is retained; removing the previous lower circular opening keeps the merged symbol quiet.

The mint options rotate the **entire unified silhouette and its lettering** eight degrees together, rather than holding a separately attached pin upright. The rounded ticket option blends its capsule-like left edge into the same lower endpoint. These are original authored vector contours, not stock shapes or traced logos.

The product assumption remains a future local free-item discovery and community reuse app. No implementation or approved identity is implied. The exact full display name **Free-Stuff-Near-You** appears in every lockup. FSNY is an optional compact initial treatment.

All twelve individual logo SVGs have transparent surrounding canvases, accessible titles and descriptions, and useful viewBoxes. Each silhouette has one continuous exterior path and a transparent tag-hole subpath using even-odd filling. Live editable text is separate from the silhouette. The dollar signs remain standard Arial Bold glyphs rather than custom strokes.

`$0` and `FSNY` use `Arial, Helvetica, sans-serif`, bold weight 700. The dollar-zero treatment is 42 units; FSNY is 22 units with 0.3 units of tracking. The full wordmark uses `Avenir Next, Trebuchet MS, Arial, sans-serif`, bold weight 700. No font files are bundled. Fallback font availability can change spacing. Before adopting a final identity, choose and license the desired final typeface and outline approved text where fixed reproduction is required; this round retains live text for editing.
